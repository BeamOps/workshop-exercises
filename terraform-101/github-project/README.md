# Your Terraform project

This is the **one project you build up across the GitHub exercises**. You work here the whole
way through: exercise `01` sets up the provider, `02` adds a repository, `03` adds a milestone,
`04` turns the token into a variable and adds issues with `for_each`, each on top of the last,
sharing one state file.

Create a `main.tf` in this folder and follow each exercise's README. Nothing in here is
committed (it's your local work and state); the `solution/main.tf` in each exercise folder
shows what your config should look like at that point.
